# Assumptions register

CLAUDE.md: _"An unresolved assumption must remain visibly unresolved. Never write it as a
confirmed capability."_

Every entry below is either `OPEN`, `RESOLVED`, or `REJECTED`. An entry only becomes `RESOLVED`
when a live seam test, transaction, or ADR proves it — never because it seems likely, and never
because a document elsewhere reads as if it were already true. `tests/docs.test.ts` fails the
build if a `RESOLVED` row carries no citation, and if any of the twelve PRD 23 questions
disappears from this table.

Rows ASM-001 through ASM-012 are the mandatory unresolved questions of PRD 23, verbatim. Rows
ASM-013 through ASM-017 are assumptions this repository introduced. Rows from ASM-018 come from
`CONDUIT_PRD_v1.1_OVERRIDE.md`, adopted in [ADR-0004](./adr/0004-prd-v1-1-override-adoption.md).

## Rules for changing this file

1. Moving a row to `RESOLVED` requires an ADR reference, a transaction hash, or a stored
   evidence artifact hash in the last column. A prose claim is not evidence.
2. A row is never deleted. If an assumption turns out to be wrong, mark it `REJECTED`, cite what
   disproved it, and open an ADR for the design change it forces.
3. New assumptions get the next free ID. IDs are never reused.
4. If code or documentation elsewhere would read as though an `OPEN` row were settled, the code
   or documentation is wrong.
