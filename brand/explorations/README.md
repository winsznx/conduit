# Explorations

The decision record for the identity, kept so a settled choice is not reopened on taste alone. The reasoning is in `../design.md` under Decision record.

These files predate the lock. Their geometry is not the final geometry (corner radii and point sizes differ from concept to concept, and the point overlaps the modules instead of sitting in a socket), so do not reuse their coordinates.

| File                                     | What it shows                                                                                                    |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `01-concept-sheet.png`                   | Six concepts in three territories, on one grid and one palette: positive, reversed, one colour, then real sizes. |
| `c1-offset.svg` to `c6-wordmark-led.svg` | The editable concept drawings behind the sheet. `c3-kiss.svg` is the pair-and-point idea before the socket.      |
| `02-survivors.png`                       | The two survivors, tested for corner radius, point size, direction, and hollow against solid.                    |
| `03-pixel-check.png`                     | Native-size renders magnified without smoothing, which chose the 4-unit grid and the point size.                 |
| `04-point-socket.png`                    | An overlapping point against a socketed one, at three clearances. The socket won.                                |
| `05-wordmark-and-lockup.png`             | Plain Geist against a module-shaped tittle, and four lockup proportions.                                         |
